# astrbot_plugin_nova_gpt_image

支持基于 GPT-5.4-all 及其它兼容 OpenAI 流式图片输出格式的大模型生图专属插件。

✨ **由全能战略官人格 Agent Nova 专属定制开发** ✨

仓库地址：[https://github.com/YumenoSayuri/astrbot_plugin_nova_gpt_image](https://github.com/YumenoSayuri/astrbot_plugin_nova_gpt_image)

## 特性

- **支持流式（Streaming）与非流式**：采用多线程异步流式截获 API 吐出的 Markdown 格式图片，第一时间推送。
- **支持多模态图生图**：在对话中附带图片，或回复（引用）带图片的聊天记录，输入触发词即可自动转换为图生图模式！
- **智能尺寸识别**：白名单用户可在 prompt 中使用 `4K`、`2K`、`1K` 配合 `16:9`、`1:1` 等比例关键词，自动生成对应分辨率的高清图片。
- **QQ 白名单系统**：支持为特定用户开启 4K 高清生图权限，非白名单用户使用默认分辨率。
- **完备的下载机制**：支持自定义超时时间、下载重试次数，确保生图成功后不再因为 CDN 慢而失败。
- **自定义配置**：支持在 AstrBot 控制面板选择全局的 Provider（例如您自建的模型代理），或者在插件面板中手动配置 API URL 和 API Key。
- **指令兼容**：可直接使用 `/GPT生图 [描述]` 或 `/GPT [描述]` 进行触发，自动识别图生图/文生图需求。
- **Images API 优化**：自动添加 `output_format: png` 和 `quality: high` 参数，确保最佳画质输出。

## 配置说明

在控制台的插件配置面板，找到 `astrbot_plugin_nova_gpt_image`：

1. **API提供商 (优先)**：如果您已在 AstrBot 配置了 Provider，可以直接选择它，插件会自动拉取其 URL 和 Key。
2. **手动配置 API URL / Key**：如果不使用 Provider，直接填入您的中转接口或直连接口。
   - 对于支持 4K 的gpt-image-2，建议使用 `/v1/images/generations` 端点以获得最佳效果。
3. **4K生图白名单（QQ号）**：填写允许使用高清生图的 QQ 号，多个用英文逗号分隔（如：`123456,789012`）。
4. **超时与重试**：根据您所使用上游 API 的网络状态，适度调整"图片下载超时时间"与"API请求等待超时"。

## 智能尺寸识别

白名单用户可在 prompt 中同时使用**质量关键词**和**比例关键词**来指定生成分辨率：

### 支持的质量关键词
- `4K` / `4k` - 超高清（最大约 830 万像素）
- `2K` / `2k` - 高清（最大约 400 万像素）
- `1K` / `1k` / `1080` - 标清

### 支持的比例关键词
支持多种写法：`16:9`、`16：9`、`16-9`、`16比9`

- `16:9` - 横屏宽屏
- `9:16` - 竖屏
- `1:1` - 正方形
- `4:3` - 传统横屏
- `3:4` - 传统竖屏
- `3:2` - 相机常用横屏
- `2:3` - 相机常用竖屏

### 尺寸映射表

| 质量 | 比例 | 实际分辨率 | 总像素 |
|------|------|-----------|--------|
| 4K | 16:9 | 3840×2160 | 8.3M |
| 4K | 9:16 | 2160×3840 | 8.3M |
| 4K | 1:1 | 2880×2880 | 8.3M |
| 4K | 3:2 | 2880×1920 | 5.5M |
| 2K | 16:9 | 2560×1440 | 3.7M |
| 2K | 1:1 | 2048×2048 | 4.2M |
| 1K | 16:9 | 1920×1080 | 2.1M |
| 1K | 1:1 | 1024×1024 | 1.0M |

### 使用示例

```
/GPT 画一只4K 16:9的小猫在海边
→ 白名单用户：生成 3840×2160 的图片
→ 非白名单用户：使用默认分辨率

/GPT 画一个2K 1:1的头像
→ 白名单用户：生成 2048×2048 的正方形图片

/GPT 画一只小猫
→ 所有用户：使用 API 默认分辨率（未指定质量和比例）
```

**注意**：必须**同时包含质量和比例关键词**才会应用自定义分辨率，只有其中一个或都没有时将使用 API 默认设置。

## 技术细节

- **超大图片支持**：自动将 `aiohttp` 读取缓冲区扩展至 100MB，完美支持 4K 图片的 Base64 传输。
- **智能端点识别**：自动识别 `/v1/chat/completions` 和 `/v1/images/generations` 端点，采用不同的请求策略。
- **多格式支持**：同时支持 Markdown 图片链接、Base64 内嵌图片、OpenAI URL 和 b64_json 格式。
- **完整日志**：记录白名单识别、尺寸解析、图片下载等关键步骤，便于调试。
